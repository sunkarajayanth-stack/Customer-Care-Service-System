# HIRA Agent Skills

These reusable skill playbooks help contributors and AI agents maintain consistent quality.

## Available Skills

### 1) `incident-triage-skill.md`
Focuses on validating incoming incident payloads, confirming risk reasoning output, and checking route-planning assumptions.

### 2) `release-hardening-skill.md`
Focuses on pre-release quality checks: API tests, frontend build checks, Docker startup checks, and docs accuracy.

## How to use
- Treat each skill as a checklist during development or review.
- Copy sections into PR descriptions for transparent QA.
- Extend with organization-specific operational policies.
